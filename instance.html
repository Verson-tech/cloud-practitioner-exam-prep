Amazon EBS:
- Used in the same AZ and can be attached to only one EC2.
- EBS volumes can be recreated through EBS snapshot for other EC2s in various AZ.
EBS Snapshot is a backup of your EBS Volume at a point in time" because EBS Snapshots serve exactly that purpose, allowing you to capture and save the state of your EBS Volume. This ensures data protection and can be crucial for recovery or replication, aligning well with essential cloud storage management practices.
- EBS storage types: EBS, EBS Archive, Recycle Bin, AMI ("EC2 Image Builder" simplifies the process of creating and managing images in an automated way, which aligns perfectly with the goal of efficiently deploying consistent environments in AWS).
- Amazon EBS (Elastic Block Store) volumes allow data to persist even after the associated EC2 instance is terminated, making them crucial for maintaining data integrity and availability.
Instance Store temporary storage for EC2 Instances:
- Instance store volumes are physically attached to the host computer and provide high I/O performance.
- Data stored in instance store volumes is lost when the instance is stopped or terminated, making it suitable for temporary data storage.
- Instance store volumes are ideal for applications that require high throughput and low latency, such as databases and data processing tasks.
